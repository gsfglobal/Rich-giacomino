# Rich World — Richgiacomino / Bee Diamonds

Sito Shopify "Rich World" per Richgiacomino / Bee Diamonds: orologi, gioielli e borse di lusso, con richieste via WhatsApp.

Negozio Shopify: `jiqvj0-ww.myshopify.com`. Il tema online si chiama **Rich World 1.1**.

## Cosa c'è in questo repository

| Cartella / file | Contenuto |
|---|---|
| `shopify-theme/` | Tema Shopify completo, identico a quello pubblicato (hero 3D, catalogo con menu, griglia TikTok, Miss Giulia) |
| `rich-world-theme.zip` | Lo stesso tema in zip, pronto da caricare su Shopify (Negozio online → Temi → Aggiungi tema → Carica file zip) |
| `shopify-setup/`, `rich-world-setup-admin.zip` | Istruzioni admin, collezioni, CSV prodotti modello, bozze delle pagine legali |
| `brand/` | Kit logo: versione originale, versione 3D e versione "cristallo" (quella in uso), favicon |
| `hero/` | Immagini 3D dell'hero: orologi, bracciale, borsa, anello |
| `prodotti2/` | Foto prodotto in uso: `-1-scuro` (sfondo del sito) e `-2-bianco` (sfondo bianco) |
| `prodotti/` | Foto prodotto originali |
| `docs/miss-giulia.md` | Configurazione dell'assistente IA Miss Giulia |
| `index.html` + immagini | Prima demo HTML del sito (GitHub Pages) |
